개인정보처리방침

조금만 가계부 · 시행일 2026년 8월 1일

요약
조금만 가계부는 서버가 없습니다. 회원가입이 없고, 가계부 내용은 사용자의 기기에만 저장됩니다. 개발자는 사용자의 어떤 개인정보도 수집·보관·열람하지 않습니다.

1. 개발자가 수집하는 정보

없습니다. 이 앱은 데이터를 전송받는 자체 서버를 두고 있지 않습니다. 회원가입, 로그인, 이메일 수집, 광고 식별자, 접속 분석 도구를 일절 사용하지 않습니다.

2. 기기에 저장되는 정보

아래 정보는 사용자의 브라우저 저장소(localStorage)에만 기록되며 외부로 자동 전송되지 않습니다.

저장 항목내용
jogeum.v1가계부 데이터 — 수입·지출 기록, 메모, 목표, 예산, 저금통, 반복 거래, 위시리스트
jogeum.sync.v1클라우드 백업 연결 정보 — GitHub 토큰 또는 구글 드라이브 파일 식별자
jogeum.ai.v1사용자가 입력한 Gemini API 키와 모델 선택
jogeum.durability.v1마지막 백업 시각, 알림 표시 상태
jogeum.promo안내 팝업을 마지막으로 본 날짜

연결 토큰과 API 키는 해당 기기에만 저장되며, 클라우드 백업 대상에서도 제외됩니다.

3. 사용자가 직접 연결했을 때만 일어나는 외부 전송

아래 기능은 기본적으로 꺼져 있고, 사용자가 설정에서 직접 연결한 경우에만 동작합니다. 전송은 사용자의 브라우저에서 각 서비스로 직접 이루어지며 개발자를 거치지 않습니다.

가) 구글 드라이브 백업
  • 전송 대상: 가계부 데이터 전체 (조금만가계부-백업.json)
  • 저장 위치: 사용자 본인의 구글 드라이브
  • 권한 범위: drive.file — 이 앱이 만든 파일만 다룰 수 있으며, 사용자의 다른 파일은 조회하거나 접근할 수 없습니다.
  • 사용자는 언제든 드라이브에서 해당 파일을 직접 열람·내려받기·삭제할 수 있습니다.
나) GitHub Gist 백업
  • 전송 대상: 가계부 데이터 전체
  • 저장 위치: 사용자 본인 계정의 비공개 Gist
  • 권한 범위: gist — Gist 외의 저장소에는 접근하지 않습니다.
다) AI 기능 (Google Gemini)
  • 전송 대상: 질문 내용과 함께 거래 내역(날짜·금액·분류·메모)과 재정 요약이 전송됩니다. 영수증 인식 기능을 쓰면 촬영한 이미지도 전송됩니다.
  • 전송처: Google Gemini API (사용자 본인의 API 키로 호출)
  • API 사용 요금은 사용자 본인에게 청구됩니다.
  • 전송된 내용의 처리는 Google의 정책을 따릅니다. 민감한 메모를 남기지 않도록 유의해 주세요.

각 서비스에 저장된 데이터는 해당 서비스의 개인정보처리방침을 따릅니다 — Google, GitHub.

4. 웹사이트 접속 기록

이 앱은 GitHub Pages로 제공됩니다. 페이지 접속 과정에서 GitHub이 IP 주소 등 접속 기록을 수집할 수 있으며, 이는 GitHub의 정책에 따릅니다. 개발자는 이 기록을 열람하지 않습니다.

5. 보관 기간과 삭제

  • 기기 데이터: 사용자가 삭제할 때까지 보관됩니다. 앱의 설정 → 전체 초기화, 또는 브라우저의 사이트 데이터 삭제로 즉시 지울 수 있습니다.
  • 클라우드 백업: 사용자 본인 계정에 있으므로, 구글 드라이브나 GitHub에서 직접 삭제할 수 있습니다. 앱에서 연결 해제를 해도 이미 저장된 파일은 남으므로, 필요하면 해당 서비스에서 삭제해 주세요.
  • 개발자가 보관하는 데이터가 없으므로 개발자에게 삭제를 요청할 대상이 없습니다.

6. 데이터 유실에 대한 안내

데이터가 기기에만 저장되는 구조상, 브라우저가 저장공간을 정리하거나 사용자가 사이트 데이터를 삭제하면 기록이 사라질 수 있습니다. 앱은 이를 줄이기 위해 저장소 보호를 요청하고 백업을 안내하지만, 완전히 막을 수는 없습니다. 중요한 기록은 클라우드 백업을 연결하거나 백업 파일을 내려받아 보관해 주세요.

7. 만 14세 미만 이용자

이 앱은 개인정보를 수집하지 않으므로 별도의 법정대리인 동의 절차를 두고 있지 않습니다. 다만 클라우드 백업이나 AI 기능은 외부 서비스 계정이 필요하며, 각 서비스의 연령 정책을 따릅니다.
